GPUIX changes replace web JSX, DOM refs, CSS styles, hidden inputs, and browser
events with native host elements, callback refs, style objects, and the native
behavior and state packages. Context slots, callback composition, and reactive
render props are adapted to this native subset. Browser forms, split radio fields,
class props, DOM render overrides, and live announcements are not ported.
