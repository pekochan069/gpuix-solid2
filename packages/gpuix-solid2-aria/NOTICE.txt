GPUIX Solid 2 Aria
=================

Copyright (c) 2026 pekochan069. Original native behavior implementations
and tooling are MIT licensed. This package implements a native subset of
the API exposed by https://github.com/pekochan069/solid2-aria, revision
4bb0e1f8c918e63c045c28d995d51dd1cf9a83b1, packages/solid2-aria.

src/filter.ts derives from packages/solid2-aria/src/i18n/create-filter.ts,
itself derived from Adobe React Spectrum
packages/react-aria/src/i18n/useFilter.ts (Copyright 2020 Adobe).
Modifications for GPUIX: use native locale provisioning, native module
paths, and repository formatting. Original copyright and derivation
notices remain in the file. See LICENSES/Apache-2.0.txt.

src/checkbox-group.ts adapts the native behavior of Solid Aria's
checkbox/create-checkbox-group.ts and create-checkbox-group-item.ts,
derived from Adobe React Spectrum's useCheckboxGroup.ts and
useCheckboxGroupItem.ts (Copyright 2020 Adobe). Modifications for GPUIX:
native host props and events, explicit state, and no DOM fields or forms.
Original copyright and derivation notices ship in source, JavaScript,
and declarations. See LICENSES/Apache-2.0.txt.

src/toggle-button-group.ts derives from Solid Aria's
button/create-toggle-button-group.ts, based on Adobe React Spectrum's
useToggleButtonGroup.ts (Copyright 2024 Adobe). Modifications for GPUIX:
native events, registered item focus, and native host props in place of
DOM toolbar listeners. Original copyright and derivation notices ship
in source, JavaScript, and declarations. See LICENSES/Apache-2.0.txt.

src/disclosure.ts derives from Solid Aria's disclosure/create-disclosure.ts,
based on Adobe React Spectrum's useDisclosure.ts (Copyright 2024 Adobe).
Modifications for GPUIX: native trigger props and events, explicit state,
and conditional panel mounting instead of DOM visibility and animation.
Original copyright and derivation notices ship in source, JavaScript,
and declarations. See LICENSES/Apache-2.0.txt.

src/tabs.ts derives from Solid Aria's tabs/create-tab-list.ts,
create-tab.ts, create-tab-panel.ts, and tabs-keyboard-delegate.ts,
based on Adobe React Spectrum's tabs hooks (Copyright 2020 Adobe).
Modifications for GPUIX: native events, mounted tab registration, native
focus and scrolling, and conditional panels instead of DOM visibility
and automatic tabbable-child detection. Original copyright and derivation
notices ship in source, JavaScript, and declarations.
See LICENSES/Apache-2.0.txt.

The upstream notice and original React Spectrum notice are preserved
verbatim in LICENSES/solid2-aria-NOTICE.txt and
LICENSES/react-spectrum-NOTICE.txt. The MIT text is in LICENSE.

Native state algorithms come from gpuix-solid2-stately. This package does
not consume @solid2-aria/core or @solidjs/web, or install DOM polyfills.
Native accessibility limitations and deferred exports are documented in
PORTING.md and native-coverage.json.
