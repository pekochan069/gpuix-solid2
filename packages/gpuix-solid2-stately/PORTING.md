# Native state audit

## Package choice

`gpuix-solid2-stately` derives its build from the published `@solid2-aria/stately@0.0.1` and `@solid2-aria/types-shared@0.0.1` artifacts. The source audit uses [solid2-aria revision 4bb0e1f](https://github.com/pekochan069/solid2-aria/tree/4bb0e1f8c918e63c045c28d995d51dd1cf9a83b1/packages/solid2-stately).

Consuming upstream unchanged would retain browser locale lookup, window-scoped validation dictionaries, virtualizer DOM test assumptions, and DOM-bound shared declarations. A handwritten state fork would duplicate portable implementations. The build therefore copies the pinned distribution and applies checked native adaptations. Other state algorithms remain shared with that release. Upstream is a build dependency, and is absent from the native production dependency graph.

`scripts/build.ts` records every emitted runtime module and whether its implementation changed in `dist/native-audit.json`. This file is regenerated by `bun run build`. The table below audits the public module families; every upstream root export and public module subpath is retained. Type-only contracts are covered separately below. Source maps are omitted because the native output changes generated code; original file notices and source paths remain intact.

## Native declarations

All state declarations resolve shared contracts inside this package. They do not expose `@solid2-aria/types-shared` to consumers. `shared-types` is a type-only entry point, as is `native-platform`.

| Upstream contract | Native contract |
| --- | --- |
| Solid `Element` for rendered children | Retained from the application's `solid-js`; supports renderer-owned objects. |
| Browser `Element`, `HTMLElement`, `HTMLInputElement`, and `HTMLOrSVGElement` targets | `NativeTarget`, an opaque `object`; no DOM methods are promised. `FocusableElement` is a compatibility name for this handle. |
| Browser focus, mouse, keyboard, submit, and pointer events | Structural native event payloads from `native-platform`. Native behavior adapters construct these payloads. |
| DOM event-map lookup | Native focus, blur, keydown, and keyup map. |
| DOM `ValidityState` | `NativeValidationDetails`, the same readonly boolean validation flags. |
| Drag preview `HTMLElement` | `NativeTarget`. |
| Dropped browser `File` | `NativeFile`, providing name, MIME type, text, and array-buffer reads. |

Link and form metadata names are retained as inert data for collection compatibility. Native adapters decide how to handle URLs, targets, form names, and validation commits. These types do not install DOM polyfills.
